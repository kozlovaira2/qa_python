3 - Установка валидного жанра для существующей книги
4 - Установка жанра для несуществующей книги
5 - Установка жанра, которого нет в списке genre
6 - Получение списка книг определённого жанра
7 - Запрос книг по жанру, когда нет книг с таким жанром
8 - Запрос книг по жанру, когда словарь пуст
9 - Книги с возрастным рейтингом отсутствуют в списке книг для детей
10 - Книга без жанра не попадает в детский список
11 - Добавление существующей книги в избранное
12 - Удаление книги из избранного
13 - Проверка, что get_books_genre возвращает актуальный словарь
